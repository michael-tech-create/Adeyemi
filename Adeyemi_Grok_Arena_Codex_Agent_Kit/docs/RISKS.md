# Risks and mitigations

| Risk | Mitigation |
|---|---|
| Slow PC freezes | Low graphics default, browser test scene, no heavy editors needed |
| AI agent scope creep | one prompt per phase, `AGENTS.md`, milestone approval |
| Two agents overwrite same files | isolate branches/worktrees or sequential handoff |
| No licenses | asset manifest and documented rights |
| Historical confusion | explicit supernatural time-travel/visions, research and fact/fiction codex |
| FPS regression | frame-time budget, performance tests, before/after measurements |
| Save corruption | schema version, validation, recoverable default |
| Browser WebGL unsupported | graceful UI and diagnostics |
| Large bandwidth | lazy loaded levels, reduced textures, compressed assets |
| Security/privacy online | keep offline-first MVP, secure server design later |
