# Roadmap and phase gates

Keep `Phase 0–7` separate. Complete acceptance for one phase before another. Timeboxes are estimates, not promises.

| Phase | Goal | Gate |
|---|---|---|
| 0 | Repo and requirements | design, scope, commands documented |
| 1 | Three.js foundation | loads, resizes, low graphics, builds |
| 2 | Movement and camera | stable controls at varied FPS, no basic clipping |
| 3 | Combat and enemy | repeatable fight, testable health/stamina, proper death |
| 4 | Forest vertical slice | full first mission and checkpoint start-to-finish |
| 5 | Art/audio/UI/save | polished without breaking mechanics, assets licensed |
| 6 | Performance QA | measured test results, no blockers |
| 7 | Public launch | deployed, tested URL, feedback channel, rollback |

**Expansion:** Chapter 2 stealth; Chapter 3 guardian trials; Chapter 4 gates; Chapter 5 final boss. New Game+, cloud save, online leaderboards, co-op only when justified by player demand and budget.
