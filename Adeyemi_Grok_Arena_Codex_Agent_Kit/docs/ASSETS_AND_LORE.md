# Art, assets and cultural research

- Prefer CC0/licensed low-poly assets for prototyping. Check each pack license and archive link/date, attribution rules, commercial status.
- Kenney https://kenney.nl/assets; Quaternius https://quaternius.com/; Mixamo https://www.mixamo.com/ ; Three.js primitive geometry as fallback.
- GLB is preferred for characters, rigged animation via `AnimationMixer`; never assume animation names or coordinate conventions without inspecting files.
- No commercial music/sfx by default. Record music rights before shipping.
- Research Oyo chronology, Benin chronology and Nok chronology independently. History codex always separates documented facts, disputed claims and fantasy inventions.
- Avoid indiscriminate 'tribal' mashups: specify a real art tradition, region, time period and rationale when creating props. Use consultants/reviewers when resources allow.

Asset registry template is in `templates/ASSET_RECORD.md`.
